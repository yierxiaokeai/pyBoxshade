Running and packaging pyBoxshade 2.0

Requirements: Python 3.10+, with PyQt5, NumPy and Biopython.
Supported dependency ranges are declared in pyproject.toml.

Windows setup (from this folder):
  python -m venv .venv
  .venv\Scripts\python -m pip install -e .
  .venv\Scripts\python -m pyboxshade

After setup, launch.ps1 opens the desktop application using PowerShell 7.
The original entry point python BS_app.py also opens the modern workspace.

Linux/macOS: replace .venv\Scripts\python with .venv/bin/python.

Development and packaging:
  python -m pip install -e .[dev]
  python -m pytest -q
  python -m build

Windows executable:
  pwsh -File build_windows.ps1
The resulting application is dist/pyBoxshade/pyBoxshade.exe.
Keep the entire dist/pyBoxshade folder together when distributing it.
GPL-3.0 applies; provide source code when distributing modified binaries.

Examples and unattended export options are documented in README.md.
